Базовые функции в Python
`input()` — считывает строку с клавиатуры (всегда строку!).
`name = input("Введите имя: ") print("Привет,", name)`

`.split()` — разбивает введённую строку по пробелам → получится список строк: `["5", "7"]`.

`map(int, ...)` — превращает каждую строку списка в целое число
- f-строка подставляет значение выражения `{a + b}` внутрь текста.
    
- Например, если `a = 5`, `b = 7`, то выведется:
    
    `Сумма: 12`

**`int()`** — превращает строку или число с точкой в целое число

**`float()`** — превращает строку или число в число с плавающей точкой.

**`str()`** — превращает любое значение в строку

**`abs(x)`** — модуль числа (всегда положительное).

**`pow(x, y)`** или оператор `x ** y` — возведение в степень.

**`round(x, n)`** — округление числа до `n` знаков после запятой.
`round(3.14159, 2)  # 3.14`

**`len()`** — длина (количество элементов).
`len("Hello")  # 5`

**`max()` / `min()`** — наибольшее и наименьшее из значений.

**`sum()`** — сумма элементов (обычно списка)

**`type()`** — показывает тип значения.
`type(5)  # <class 'int'>`

**`range()`** — создаёт последовательность чисел (часто используется в циклах).
`for i in range(3):    
        print(i)   # 0, 1, 2

**`map()`** — применяет функцию ко всем элементам.
`list(map(int, ["1", "2", "3"]))  # [1, 2, 3]``
